# AI LLM Leaderboard

**Real-time LLM rankings for every use case.**

Find the best AI model for **Coding**, **Arabic**, **Legal**, **Science**, **Marketing**, **Python**, **JavaScript**, and 50+ specialized categories.

---

## 🌟 Features

- **Real-time Leaderboards** – Updated daily with fresh benchmarks
- **Use Case Rankings** – Programming, Legal, Marketing, Science, SEO, Finance, Health, Roleplay & more
- **Multilingual Leaderboards** – Arabic, English, Hindi, Chinese, French, Spanish, Bengali & 40+ languages
- **Programming Language Rankings** – Python, JavaScript, TypeScript, Rust, Go, Java, C++, SQL & more
- **Model Directory** – Browse 500+ LLMs
- **Mobile Responsive** – Beautiful light and dark UI

## 🧑‍💻 Getting Started

### Prerequisites

- Node.js 20+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/ai-llm-leaderboard.git
cd ai-llm-leaderboard

# Install dependencies
npm install
```

### Run development server

```bash
npm run dev
```

### Run production server

```bash
npm run build
```
